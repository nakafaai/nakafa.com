# ADR 0006: Versioned Public API And Stable Protected Capabilities

> Superseded in part by [ADR 0037](0037-cloudflare.md): the hosting, delivery, and deployment decisions of this record no longer apply.

## Status

Accepted for the Nakafa public API boundary correction. Amended on 13 October
2026 for the school REST API and MCP server, which live on the school host and
carry their own credential. ADR 0029 owns the school integrations, and ADR 0026
owns the host.

## Context

External REST consumers need one explicit public path that names the current
contract. Nakafa deployment components also need a direct, stable protected
contract that does not accumulate public version vocabulary.

Nakafa has only one public REST contract, V1.

Schools also need an API of their own. It carries a credential and school data,
which the public API refuses by design, so it cannot share the public host, the
public namespace, or the public bridge.

## Decision

The public REST API names its current contract by one path prefix, `/v1`:

```text
https://api.nakafa.com/v1
https://api.nakafa.com/v1/health
https://api.nakafa.com/v1/search
https://api.nakafa.com/v1/content
https://api.nakafa.com/v1/taxonomy
https://api.nakafa.com/v1/quran/{surah}
```

`https://api.nakafa.com/openapi.json` remains the unversioned discovery
document. Every resource path inside that document uses `/v1`. The shared
`NAKAFA_PUBLIC_API_PATH` owns this path for OpenAPI, the CLI, tests, and
documentation. The API edge contract in `packages/backend/agent/edge.ts` names
the same value, and an exact test proves both values equal. The public contract
version remains within `1.x`.

A breaking change to the public contract ships in one step: its path, schemas,
OpenAPI document, CLI, and tests change together. No predecessor path and no
compatibility namespace is kept (see the Change Rule below).

The contract covers response schemas as well as paths, so a payload change
updates the OpenAPI document and its decoders in the same change.

Protected Convex capabilities are stable and unversioned:

```text
/internal/agent/runtime
/internal/agent/openapi
```

These paths are deployment seams, not public consumer contracts. The API edge
Worker maps `/v1` resources to `/internal/agent/runtime` and maps
`/openapi.json` to `/internal/agent/openapi`. Protected paths must describe
capabilities, never public API versions or public filename conventions.

The protected MCP transport is a capability of the same kind:

```text
/internal/mcp
```

Effect's `McpServer` (`effect/ai`) serves that path inside the Confect HTTP
route, built for each request. Nakafa keeps the work in front of the engine and
around it: the edge secret, the exact origin allowlist, the 64 KiB body cap, the
rate limit, the CORS and cache headers, the eight methods it serves, the
discovery capabilities it declares, every tool, resource, and prompt definition,
the tool result envelopes, and the refusals that the engine would answer with
another status, code, or body. Those refusals are other methods, non-JSON
bodies, malformed and batched bodies, a predecessor protocol version, and
JSON-RPC notifications, which get `202` without a body when they carry the
protocol version header. The engine answers everything else. A refusal that the
engine words differently keeps its code and status, and its message may take the
engine's wording.

Production has no public unversioned resource aliases and no versioned protected
aliases.

## School API

Planned. The school REST API and the school MCP server live on the school's own
host, which ADR 0026 owns:

```text
https://harapan.nakafa.com/api/v1
https://harapan.nakafa.com/mcp
```

The host already names the school, so the path does not repeat it. The public
decisions above do not change. `https://api.nakafa.com/v1` and
`https://mcp.nakafa.com/mcp` stay without a key, serve public Nakafa content
only, and never accept a school path.

- The only credential the school API accepts is a bearer token. An integration
  gets its token through OAuth 2.0 client credentials, and the CLI gets one
  through device authorization on behalf of a person. ADR 0029 owns both flows
  and the rules of the token. Its OpenAPI document and the protected resource
  metadata of its MCP server hold no school data and need no token.
- `/api/v1` names the current school contract, not a compatibility namespace. A
  breaking change to a school path or payload ships in one step, with the school
  clients that call it.
- One `HttpApi` definition owns the paths, the schemas, and the OpenAPI document
  of the school API (ADR 0029). The public document stays at
  `https://api.nakafa.com/openapi.json`, served through
  `/internal/agent/openapi`, and never lists a school path.
- The protected capability paths above serve the public API only. The edge
  Workers of the public API delete the `authorization` and `cookie` request
  headers (`agentEdgeRequestHeaders` in `packages/backend/agent/route.ts`), so
  they cannot carry the school API, and no school path is added to them.
- The school paths reach Convex through the web project of the school's own data
  cell, never through the public bridge and never through another cell
  (ADR 0026, ADR 0029).

## Change Rule

A contract changes in one step. The backend and the apps deploy together: the
Convex functions, the API and MCP edge Workers, and the web app. A brief break
during that deploy is accepted. A rename or removal deletes its predecessor in
the same change, with its tests and comments. No predecessor path, alias, dual
read, observation window, or temporary function is kept, and no older client is
waited for.

## Consequences

- Public consumers keep a clear `/v1` contract.
- Internal maintainers use stable capability names without version churn.
- CLI and OpenAPI paths derive from one public path owner.
- Public path major and reported contract major cannot intentionally diverge.
- Workspace package versions never redefine the public API path or reported
  contract major.
- Public V1 response schemas match the code that serves them.
- Unknown nested paths such as `/v1/openapi.json` reach the protected runtime
  and return the normal structured missing-endpoint response instead of
  colliding with the OpenAPI document capability.
- Every change deletes its predecessor paths and tests in the same change.
- The school API has its own host, namespace, and credential. A change to it
  cannot break a public consumer, and the public bridge cannot expose school
  data.
