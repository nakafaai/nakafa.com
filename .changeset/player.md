Run every try-out section in a new player. The header stays one row on
phones, with the timer and one Selesai button whose confirmation lists flagged
and unanswered questions. Learners can switch between all questions and one
question at a time, jump with a numbered navigator (a sidebar on wide screens,
a sheet on phones), flag questions to revisit, and use keyboard shortcuts.
Answers and flags show at once, and finishing keeps the questions on screen
until the next page is ready instead of showing a spinner. The responsive
dialog accepts where focus returns and a callback after it closes.
